# NASA OSDR fixture — Inspiration4 complete blood count

- **File:** `OSD-569_CBC_TRANSFORMED.csv` — unmodified copy of `LSDS-7_Complete_Blood_Count_CBC_TRANSFORMED.csv`
- **Source:** NASA Open Science Data Repository, study **OSD-569** (Inspiration4 whole blood) — https://osdr.nasa.gov/bio/repo/data/studies/OSD-569
- **Direct file:** https://osdr.nasa.gov/geode-py/ws/studies/OSD-569/download?source=datamanager&file=LSDS-7_Complete_Blood_Count_CBC_TRANSFORMED.csv
- **Content:** 4 anonymised crew (C001–C004) x 7 time points (L-92, L-44, L-3, R+1, R+45, R+82, R+194 days). Pre/post-flight only — the mission lasted 3 days, so there are **no in-flight samples**.
- Check the OSDR terms of use before redistributing outside this project. Re-download with `npm run import:osdr -- --download`.
